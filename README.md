# 📖 About

PHP Foundation is a structured collection of PHP concepts, examples, exercises, and mini-projects designed to help you build a strong understanding of server-side programming.

Whether you're:
- 🎓 A student learning PHP
- 💼 Preparing for technical interviews
- 🌐 Starting WordPress development
- ⚡ Moving toward Laravel or backend engineering

This repository aims to be your one-stop PHP learning resource.

---

# 🎯 Learning Objectives

After completing this repository, you'll be able to:

- Understand PHP syntax and programming fundamentals
- Work with variables, arrays, loops, and functions
- Build dynamic web pages
- Handle forms and user input
- Manage sessions and cookies
- Connect PHP with MySQL databases
- Perform CRUD operations
- Apply Object-Oriented Programming concepts
- Write cleaner and more maintainable PHP code

# ⚙️ Getting Started

## Clone the repository

```bash
git clone https://github.com/singhdigvijay99/php-foundation.git
```

## Move into the project

```bash
cd php-foundation
```

## Start PHP Development Server

```bash
php -S localhost:8000
```

Open:

```
http://localhost:8000
```
